Concierge keeps the right people informed as new Craft user accounts move through registration and activation. Notify moderators when someone signs up and let the new member know when access is ready.

Choose a Craft user group to receive registration notifications. Used with Craft’s option to deactivate new users by default, Concierge gives the review team a timely prompt without changing the account-status rules you already use.

## Features

- **Registration alerts:** Tell the nominated moderator group when a new user signs up.
- **Group recipients:** Route moderation notices to every user in the selected Craft group.
- **Activation messages:** Let a user know when their account has been activated.
- **System Messages:** Edit notification content through Craft’s familiar email-message controls.
- **Independent controls:** Enable registration and activation emails separately.
- **Configurable setup:** Manage recipient groups and notification switches in settings or config.
- **Activation emails:** Send an activation message when a moderator enables the account. Message content lives in Craft’s System Messages utility, keeping the wording editable alongside other account emails.
