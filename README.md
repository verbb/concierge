<h1 align="center">Concierge for Craft CMS</h1>

Concierge is a Craft CMS plugin that keeps the right people informed as new Craft user accounts move through registration and activation. Notify moderators when someone signs up and let the new member know when access is ready.

Choose a Craft user group to receive registration notifications. Used with Craft's option to deactivate new users by default, Concierge gives the review team a timely prompt without changing the account-status rules you already use.

## Features

- Tell the nominated moderator group when a new user signs up.
- Route moderation notices to every user in the selected Craft group.
- Let a user know when their account has been activated.
- Edit notification content through Craft's familiar email-message controls.
- Enable registration and activation emails separately.
- Manage recipient groups and notification switches in settings or config.
